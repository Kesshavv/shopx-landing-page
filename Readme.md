# 🛍️ ShopX - Animated E-commerce Landing Page

A modern and responsive **e-commerce landing page** built using **HTML, CSS, and JavaScript**, featuring smooth animations and a floating GitHub button.

---

## 🚀 Live Features

* ✨ Smooth hero section animations
* 🛒 Product showcase cards
* 📱 Fully responsive design
* 🎯 Scroll-based reveal animations
* 💡 Hover effects & interactive UI
* 🐙 Floating animated GitHub button (bottom-right corner)
